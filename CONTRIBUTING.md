# Contributing

Thanks for contributing to this AutoCAD design website.

## Workflow

1. Create a focused branch from `main`.
2. Keep HTML, CSS, and JavaScript changes scoped to the feature being changed.
3. Test the affected pages in a modern browser at desktop and mobile widths.
4. Update `README.md` when project structure, setup, or deployment instructions change.
5. Do not commit private customer data, credentials, or deployment secrets.

## Pull requests

Include a concise description of the change, pages affected, browser/device checks performed, and screenshots for meaningful visual changes.
